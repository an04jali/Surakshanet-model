# 🛡️ SurakshaNet — AI-Powered Crowd Safety & Suspicious Activity Detection

> AI-powered surveillance system for real-time person detection, crowd risk analysis, suspicious activity detection, and instant Telegram alerts.

## 🚀 Live Demo

**[🌐 Try SurakshaNet](https://surakshanet-ai.streamlit.app/)**

### Key Features

- 📹 Browser-based live webcam monitoring
- 📤 Video upload & analysis
- 👥 YOLOv8 person detection
- ⚠️ Crowd risk assessment
- 🧠 Suspicious activity detection
- 🔥 Activity heatmap
- 🗺️ Zone-based monitoring
- 📊 Analysis history
- 🔔 Alert history
- 📱 Real-time Telegram alerts
